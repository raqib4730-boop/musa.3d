MUSA 3D WEBSITE
================

1. Extract this folder.
2. Open index.html in a modern browser.
3. All uploaded images/videos are already included in assets/.

Features:
- Full-screen cinematic hero video
- 3D mouse parallax on hero
- Interactive 3D product card tilt
- Scroll reveal animations
- Video/image product sections
- Responsive mobile layout

No build tools are required.
